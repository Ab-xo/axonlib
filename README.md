# AxonLib

A lightweight neural-network library built from scratch with Python and NumPy. AxonLib focuses on the core mechanics of a deep-learning workflow rather than hiding them behind a high-level framework.

## Features

- Dense affine layers
- ReLU activation
- Mean squared error loss
- Stochastic gradient descent
- Sequential model API
- Mini-batch data loading
- Unit tests for layers and training behavior

## Technology

- Python
- NumPy
- unittest

## Installation and testing

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

## Status

Early-stage educational library intended for learning and incremental expansion.
